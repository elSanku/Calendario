# Skill: SDD-Change

Permite introducir modificaciones a una especificación activa sin alterar código a ciegas.

## Proceso
1. **Actualización de la Spec (`spec.md`)**:
   - Ajustar los requerimientos funcionales y criterios de aceptación.
2. **Impacto en el Plan Técnico (`plan.md`)**:
   - Analizar componentes UI (`src/components/`), tipos (`src/types/`), utilidades de fechas (`src/utils/`) o estilos (`.module.css`) afectados.
3. **Ajuste de Tareas (`tasks.md`)**:
   - Agregar o modificar las tareas atómicas conservando el orden de ejecución y trazabilidad.
