# Habilidad: Flujos de Pruebas Manuales (Manual Testing Flows)

## Descripción General

Esta habilidad genera un plan breve de pruebas manuales con los 2 o 3 flujos de usuario más importantes, basándose en la estructura del proyecto y en las pruebas existentes.

## Instrucciones

- Analizar la estructura del proyecto para comprender las funcionalidades principales.
- Buscar y revisar las pruebas existentes para identificar los flujos clave y los casos límite.
- Seleccionar los 2 o 3 flujos de usuario más importantes (los más comunes o de mayor riesgo).
- Para cada flujo, redactar:
  - Precondiciones (si son necesarias)
  - Pasos a seguir (numerados)
  - Resultado esperado

## Resultado Esperado

- De 2 a 3 flujos de prueba manual con pasos claros y resultados esperados
